THE SEA CAME TO THE SKY — a colossal whale breaches through a sea of clouds
above a sleeping night city, lit by the moon and the city's warm glow. The
program draws the whole image procedurally, in code, with a seeded random
generator: no external images, no network, no model calls. Two runs write
byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes a 1024x1024 PNG to `out/entry.png`.
